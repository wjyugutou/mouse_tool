### ✨ 新功能 · Features

- **双模式色彩与能量光谱系统**：重构深浅两套 `oklch` 主题配色，区分画布、侧栏控制坞与主控卡片材质层；建立统一的电量档位渐变与语义色板，主窗口氛围光随当前设备能量状态柔和联动。
- **腕表级 60 刻度精密能量环**：重绘 Canvas 2D 电量仪表盘，新增外圈 60 格随电量点亮的表盘刻度、内侧校准细环、圆锥渐变能量弧、光学弥散辉光、末端高光能量珠与等宽数字排版。
- **硬件遥测主控台**：主卡片加入顶部能量灯带与微高光棱线，新增 10 格精密电芯能量矩阵、独立凹槽三联遥测数据仓，以及等宽字体终端风格的可折叠诊断面板。
- **外设控制坞侧栏与精灵视窗**：升级 `MorphBot` 电子精灵视窗与凹槽式分类滑块；侧栏设备项直接读取现有快照展示各外设实时微电量胶囊与左侧能量光条，顶部新增在线设备计数微标。
- **精密分段标题栏与分组偏好设置页**：标题栏重构为分段导航胶囊并支持新版本提醒微点；设置页改为居中分组式桌面偏好布局，新增双栏分段开关、带设备图标的托盘多选模块卡、浅色/深色/跟随系统迷你窗口预览色卡与下载进度条。
